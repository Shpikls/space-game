# CLAUDE.md

Одиночная космическая игра на TypeScript + React. Дизайн — `docs/design.md`, план работ — `docs/roadmap.md`.
Рабочие прототипы (один HTML-файл каждый) лежат в `public/prototype/`: это эталон поведения при переносе.

## Команды

- `npm run dev` — запуск; прототипы доступны по `/prototype/world.html` и `/prototype/combat.html`
- `npm test` — тесты (Vitest)
- `npm run typecheck` — проверка типов
- `npm run build` — сборка

## Архитектура

- `src/data` — только данные и типы: оружие, враги, корабли, модули, системы. Баланс меняется здесь.
- `src/sim` — чистая симуляция. **Никакого DOM, React и отрисовки.** Случайность только через `Rng` из `sim/rng.ts`, чтобы прогоны повторялись в тестах.
- `src/game` — состояние игры, фит, задания, экономика, прогон заданий для баланса.
- `src/render` — отрисовка на canvas, читает состояние и события симуляции.
- `src/ui` — React-компоненты.

Связь симуляции с остальным — через события `SimEvent`, которые возвращает `stepScene`.

## Правила

- Перед изменением механики сверяйся со столпами в `docs/design.md`. Главный: подготовка даёт 95% успеха, манёвры в бою — 5%.
- Любая правка чисел баланса → прогон `npm test`. Тесты в `tests/balance.test.ts` фиксируют, что правильный фит побеждает без вмешательства игрока, а неправильный проигрывает. Если правка намеренно меняет баланс — обнови тест и объясни почему.
- Новая механика в `src/sim` — с тестом.
- Интерфейс на русском, проверяй на узком экране телефона (~380 px): всё помещается без прокрутки.
- Небольшие шаги: каждый шаг заканчивается рабочей версией.
