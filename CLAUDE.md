# CLAUDE.md

Одиночная космическая игра-песочница в браузере (вдохновение: EVE Online, «Космические рейнджеры»). Разработка в основном с телефона (Claude Code в облаке) и короткими сессиями на компьютере, поэтому весь контекст живёт в репозитории.

Перед работой прочитай:
- `docs/VISION.md` — цель, опоры, вехи
- `docs/DESIGN.md` — принятые решения (не переоткрывай их без запроса)
- `ROADMAP.md` — что делать дальше

Общение и тексты в игре — на русском.

## Стек

- TypeScript (strict), Vite, three.js, Vitest
- Интерфейс (HUD, обзор, debug-панель) — пока обычный DOM + CSS, как в прототипе
- Деплой: GitHub Pages через GitHub Actions

## Команды

- `npm run dev` — локальный сервер
- `npm test` — тесты
- `npm run typecheck` — проверка типов
- `npm run build` — сборка

## Структура

- `src/sim/` — симуляция: физика кораблей, приказы, варп, бой, экономика. **Без three.js и DOM.** Детерминированная: случайность только через RNG с сидом.
- `src/render/` — three.js: рендер относительно корабля игрока (floating origin), logarithmic depth buffer.
- `src/ui/` — HUD, обзор, debug-панель.
- `src/scenarios/` — сценарии как данные, загружаются через URL.
- `prototype/` — исходный прототип одним HTML-файлом, только для справки.

## Правила работы

- Одна задача из `ROADMAP.md` = один PR. Маленькие шаги.
- Новая логика в `src/sim` — с тестами в Vitest.
- Mobile-first: всё управление должно работать пальцем, кнопки не меньше 40px, учитывать safe-area.
- Единицы: метры, секунды, радианы в симуляции. Позиции — JS-числа (double).
- Всё, что нужно проверять, должно быть доступно через сценарий в URL или debug-панель, без прохождения игры.
- В конце сессии: отметить пункт в `ROADMAP.md`, добавить строку в «Журнал», закоммитить и запушить.
- Если по ходу принято новое решение по дизайну — дописать его в `docs/DESIGN.md`.
