- [x] Vite + TypeScript + three.js, структура `src/sim`, `src/render`, `src/ui`, `src/scenarios`
- [x] Перенести прототип `prototype/xanta-warp.html` в модули (поведение не меняем)
- [x] Vitest: тесты симуляции (время выравнивания и варпа по корпусам, радиус орбиты, дистанция выхода из варпа)
