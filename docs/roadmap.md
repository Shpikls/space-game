# План переноса из прототипов

Каждый шаг заканчивается рабочей версией. Порядок можно менять.

1. ~~Каркас: Vite, React, TypeScript, Vitest.~~
2. ~~Ядро симуляции в `src/sim`, данные в `src/data`, тесты боя и баланса.~~
3. Отрисовка космоса на canvas (`src/render`): корабли, астероиды, выстрелы, всплывающий урон, HUD. Источник — `render()` в `public/prototype/world.html`.
4. Игровой цикл: фиксированный шаг 1/60 с, множитель темпа 0,7, события симуляции → эффекты и журнал.
5. Боевая панель на React: приказы, дистанции, карточка цели, журнал.
6. Станция на React: задания, ангар, рынок.
7. Навигация: карта систем, варп и прыжки.
8. Сохранение состояния игры (localStorage, затем IndexedDB).
9. Удалить прототипы, когда новая версия умеет всё то же самое.
